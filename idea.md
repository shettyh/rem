# Idea

I am basically looking for a produvtive and efficient way to remember things, Like ankidroid but less clunky UI. 

- A clean markdown based editor to add question and answer, that should support text, code, image etc.
- Algorithm as string as ankidroid's to create study plans
- Namespacing support for organising different card decks


Lets build a great MVP first and then iteratively build on top. Ideally better if it is webapp for now

Main themes are clean, simple, correct. Write maintainable and modular code that are easy to maintain and modify
