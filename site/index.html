Agent Skill + CLI

Already in your agent’s context.
Engineered to keep AI slop out.

Most flashcard workflows fail at capture time — copying context into another app breaks flow, while unguided LLMs produce bloated cards you dread reviewing. Pairing the bundled rem CLI with the installable rem-card-capture skill turns any CLI-capable agent into a disciplined spaced-repetition collaborator.

Read SKILL.md CLI reference
01

Any agent, zero plumbing

Works directly with Claude Code, Codex, pi, Cursor, Amp, or shell scripts over a plain CLI — no MCP server, no API key lock-in, and works even while the desktop app is closed.

02

Card craft built into the skill

rem-card-capture enforces the 3-month / 5-second test, caps batches at 3 atomic recall targets (zero is valid), prefers mechanism, contrast, and diagnosis prompts over essays or yes/no trivia, and keeps Markdown clean for desktop, iPhone, and terminal.

03

Machine-safe, retry-proof CLI

Agents resolve exact deck IDs, search existing cards via rem card search and pending drafts via rem draft list, validate every batch with --dry-run and --output json, and get retry-safe duplicateCard / duplicateDraft no-ops.

04

Local drafts, terminal triage & provenance

Proposals land in the local-only Drafts inbox — triage them on Desktop or in the shell with rem draft review (front-first TUI with $EDITOR handoff). Accepted cards retain their rationale and source locators during review; rem card add and rem sync stay ready for scripts.

You → Claude Code / Codex / pi

“We just fixed that stale-grade race condition — capture what’s worth remembering in my Rust internals deck.” 

# 1. Skill resolves target deck and validates batch with --dry-run
$ rem deck list --output json
$ rem draft add --deck rust-internals --producer claude-code \
    --input-json - --dry-run --output json <<'JSON'
[{
  "front": "In rem, how does optimistic concurrency prevent desktop and terminal sessions from grading the same stale card twice?",
  "back": "Each study item carries local_revision; committing succeeds only if it still matches, else returns a conflict without logging.",
  "tags": ["rust", "concurrency"],
  "rationale": "Core invariant across shared SQLite surfaces.",
  "sources": [{ "locator": "src-tauri/crates/rem-core/src/study.rs:142-168" }]
}]
JSON

# 2. Dry-run passes → submits identical payload without --dry-run
{ "version": 1, "command": "draft.add", "data": { "drafts": [{ "status": "created" }] } }

Terminal · Trusted scripts · CI

Bypass drafts when you want immediate scheduling, import Anki decks, review Markdown cards in your shell, and sync in real time to Desktop and iPhone.

$ rem card add --deck Systems --input-json notes.json --output json

$ rem import anatomy.apkg --dry-run
$ rem import anatomy.apkg

$ rem study --deck Systems

# Fast snapshot bootstrap & incremental sync via Keychain or REM_SYNC_TOKEN
$ rem sync status

Instant FTS5 search

Search front, back, tags, and rationale across every deck in milliseconds via trigger-maintained SQLite FTS5 (with substring fallback for code operators) using ⌘K on desktop, Decks search on iPhone, or rem card search.

FSRS-7 & Custom Study

Modern FSRS-7 scheduling in Rust with Anki-aligned steps, configurable retention, sibling burying, Custom Study modes, and per-deck weight optimization across desktop and iPhone.

Agent Skill, TUI & Provenance

Anki import, Cloze & LaTeX

Import Anki .apkg decks on desktop, CLI, or iPhone with revlog replayed into FSRS-7. Write cloze deletions with sibling burying, LaTeX math, inline audio clips, nested :: subdecks, and highlighted code.

Native iOS companion

SwiftUI iPhone app backed by the same Rust core via UniFFI — direct .apkg import on iPhone, Image Occlusion, native LaTeX math, audio playback, nested :: subdecks, Custom Study, global search, Swift Charts stats, and reminders.

Cloud Sync v1.1

Real-time WebSocket pokes, fast compacted snapshot bootstrap for new devices, and 500 MB R2 media for images, occlusion diagrams, and audio via rem Premium (30-day free trial, $5/year) — or self-host the Apache-2.0 Worker free.
