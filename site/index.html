Agent Skill + CLI

Already in your agent’s context.
Engineered to keep AI slop out.

Most flashcard workflows fail at capture time — copying context into another app breaks flow, while unguided LLMs produce bloated cards you dread reviewing. Pairing the bundled rem CLI with the installable rem-card-capture skill turns any CLI-capable agent into a disciplined spaced-repetition collaborator.

Read SKILL.md CLI reference
01

Any agent, zero plumbing

Works directly with Claude Code, Codex, pi, Cursor, Amp, or shell scripts over a plain CLI — no MCP server, no API key lock-in, and works even while the desktop app is closed.

02

Card craft built into the skill

rem-card-capture enforces the 3-month / 5-second test, caps batches at 3 atomic recall targets (zero is valid), prefers mechanism, contrast, and diagnosis prompts over essays or yes/no trivia, and keeps Markdown clean for desktop, iPhone, and terminal.

03

Machine-safe, retry-proof CLI

Agents resolve exact deck IDs, inspect pending drafts, validate every batch with --dry-run and --output json before writing, get retry-safe duplicateCard / duplicateDraft no-ops, and verify versioned version: 1 JSON.

04

Local drafts by default, direct CLI when you ask

Every proposal lands in the local-only Drafts inbox with rationale and exact file paths, line ranges, commits, or URLs. When you explicitly want immediate scheduling or scripted pipelines, rem card add and rem sync are right there.

You → Claude Code / Codex / pi

“We just fixed that stale-grade race condition — capture what’s worth remembering in my Rust internals deck.” 

# 1. Skill resolves target deck and validates batch with --dry-run
$ rem deck list --output json
$ rem draft add --deck rust-internals --producer claude-code \
    --input-json - --dry-run --output json <<'JSON'
[{
  "front": "In rem, how does optimistic concurrency prevent desktop and terminal sessions from grading the same stale card twice?",
  "back": "Each study item carries local_revision; committing succeeds only if it still matches, else returns a conflict without logging.",
  "tags": ["rust", "concurrency"],
  "rationale": "Core invariant across shared SQLite surfaces.",
  "sources": [{ "locator": "src-tauri/crates/rem-core/src/study.rs:142-168" }]
}]
JSON

# 2. Dry-run passes → submits identical payload without --dry-run
